# 02 - Design Decisions

This folder is the conversation record for the page's visual direction. We can change these decisions as we work; the local build should follow the latest approved version.

## Direction to explore

- Overall feeling: Editorial, quiet, tactile, and human.
- Three words the page should feel like: Grounded, considered, spacious.
- Three words it should not feel like: Corporate, glossy, crowded.
- Relationship to the existing studio brand: To be confirmed.
- Reference websites or examples: Pinterest board, `Altitude Website`.

## Visual system

- Primary color: Warm ivory / paper.
- Supporting colors: Muted olive, stone, smoke, and soft black.
- Text color: Near-black charcoal.
- Background color: Warm ivory with occasional deep charcoal sections.
- Accent color: Muted olive or earthy brown, pending studio branding.
- Heading font: High-contrast editorial serif.
- Body font: Small, clean sans serif for navigation, labels, and supporting copy.
- Border and corner style: Fine rules; modest rounding on image containers only.
- Image treatment: Large, atmospheric, slightly tactile photography with consistent crops.

## Layout

- Header/navigation: Minimal utility navigation with generous breathing room.
- Intro section: Oversized serif statement paired with a strong image area.
- Teacher card arrangement: Editorial grid with photography leading each teacher entry.
- Teacher card details: Name, role, short bio, and specialties; avoid dense UI.
- Mobile behavior: Stack the editorial composition; preserve image presence and whitespace.
- Call-to-action placement: Quiet text-led CTA after the teacher stories.
- Footer or next section: Simple, low-contrast studio details.

## Interaction

- Should cards expand, link to profiles, or stay simple?
- Should visitors filter by specialty or class type?
- Should there be motion? If so, where should it be subtle and useful?
- What should keyboard and screen-reader users experience?
