# Changelog — Altitude Yoga website

Human release versions, newest first. The first `## x.y` heading below is the version the
live site shows in every page footer, next to when that version was last updated (Eastern
time). Publishing fills both in (`.github/stamp-version.sh`); a page opened from your own
computer says "Local preview · not published" instead.

Bump the minor (1.x) for content and design changes, the major for a new site structure.
Add the entry in the same commit as the change.
