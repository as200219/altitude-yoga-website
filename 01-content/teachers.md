## Image checklist

- Get permission to use every teacher photo.
- Use clear, well-lit images with a consistent crop.
- Keep original high-resolution files outside the code folder if needed.
- Export web-ready images and keep filenames simple.
- Write useful alt text that identifies the teacher without describing decorative details.

## Copy checklist

- Confirm spelling, titles, pronouns, specialties, and links with each teacher.
- Keep card introductions scannable.
- Avoid promising outcomes that the studio cannot guarantee.
- Use one consistent voice across all teacher entries.
